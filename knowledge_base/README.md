# 知识库文档说明

## 目录结构

```
knowledge_base/
├── README.md              ← 本文件
├── RAG原理与应用.md        ← RAG 检索增强生成原理详解
├── Agent架构与设计.md      ← Agent 系统架构设计
└── 机器学习笔记.pdf        ← 吴恩达机器学习课程笔记（完整版）
```

## 知识库配置参数

在 Dify 中导入这些文档时，推荐使用以下配置：

| 参数 | 推荐值 |
|------|------|
| 分块大小 | 500 tokens |
| 分块重叠 | 50 tokens |
| 分隔符 | `\n\n` |
| Embedding 模型 | text-embedding-v3 |
| 检索策略 | 混合检索（语义 + 关键词） |
| Rerank 模型 | qwen3-rerank |
| Top-K | 4 |
| Score 阈值 | 0.3 |

## 如何扩展知识库？

直接在 Dify 的知识库管理页面上传新文档即可，系统会自动进行向量化处理。

**注意**：上传新教师的资料时，建议同时更新 `SERACH_TEACHER` 节点的系统提示词，将新老师加入可选列表。
