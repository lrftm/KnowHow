# 作品简介

**项目名称**：知其然 —— AI 苏格拉底式自适应学习助手

**所选赛题**：教育领域 AI Agent 应用

**目标用户**：AI/ML 领域自学者、在校学生

---

## 核心问题

当前 AI 学习工具（如 ChatGPT、通义）存在共同问题：用户一问，AI 直接给出完整答案。这种方式导致用户只是"看懂了"，而不是"真正理解了"。大量研究表明，主动回忆和自主推导才是深度学习的关键。

## 解决方案

"知其然"采用**苏格拉底式对话**作为核心教学方法：

- 不直接回答用户的问题，只提供引导性追问
- 通过持续追问，引导用户自己推导出答案
- 结合 RAG 从教材知识库中检索依据，确保引导方向准确

## 创新点

1. **苏格拉底式 Agent**：业界少见的"拒绝回答"型 AI，核心行为是追问而非解答
2. **多教师热插拔**：运行时随时切换教师风格（吴恩达/李沐），无需重启对话
3. **学习/复习双模式**：分类路由至不同 Agent，学习模式引导探索，复习模式考查掌握度
4. **RAG 知识引用**：回复附带知识库来源引用，可追溯，防幻觉

## 技术路线

Dify Chatflow + deepseek-v4-flash + RAG（text-embedding-v3 + qwen3-rerank）

## 开放/复用价值

- Dify DSL 文件开源，可一键导入复现
- 教师档案和知识库文档开源，可扩展更多老师和学科
- 苏格拉底式提示词框架可复用于其他教育场景
